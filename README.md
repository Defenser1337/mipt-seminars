# MIPT Seminars

Seminar materials on Python internals and ML engineering.

## Seminars

| Directory | Topic |
|---|---|
| [`tracking-seminar`](tracking-seminar/) | Experiment tracking with TensorBoard, MLflow, Weights & Biases, and Comet: notebook, talk notes, and cleanup tooling |
| [`py-gc-seminar`](py-gc-seminar/) | Python garbage collection: reference counting, cycles, generations, weak references, and leak diagnostics |

## Usage

Each seminar directory is self-contained and has its own `README.md` with setup
and run instructions, plus a `requirements.txt` where needed.

```bash
git clone https://github.com/Defenser1337/mipt-seminars.git
cd mipt-seminars
```
